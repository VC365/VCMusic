# Building

## Dependencies

- `Crystal` - `~1.21.0`
- `GTK`
- `libadwaita`
- `gettext`
- `gstreamer`
- `gstreamer-pbutils-1.0`
- `rubberband-ladspa` (optional)

### Makefile

1. `$ make`
2. `# make install` # To install it
